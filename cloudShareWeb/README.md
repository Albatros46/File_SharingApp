# CloudShare – Frontend

React 19 + Vite 8 + Tailwind CSS 4.

```bash
npm install
cp .env.example .env
npm run dev      # Entwicklungsserver auf http://localhost:5173
npm run build    # Produktions-Build nach dist/
```

Die vollständige Dokumentation steht in der [README im Projektstamm](../README.md).
